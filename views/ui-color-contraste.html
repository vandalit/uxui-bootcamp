Color y contraste

El color comunica significado y guía la atención — el contraste determina si ese significado es legible y accesible para todos.

Paleta funcional

Primario (marca/acción principal), secundario (apoyo) y neutros (texto, fondos, bordes) — cada color con un rol claro, no decorativo al azar.

Color por estado

Convenciones que el usuario ya espera: verde = éxito, rojo = error, amarillo = advertencia, azul = información.

Contraste WCAG

Ratio mínimo de luminosidad entre texto y fondo — 4.5:1 para texto normal, 3:1 para texto grande, según el estándar AA.

Daltonismo

No depender solo del color para comunicar (ej. error). Sumar un ícono o texto para que la información no se pierda con baja percepción de color.

Modo claro / oscuro

Cada color funcional necesita su versión en ambos modos — el contraste debe mantenerse válido en los dos, no solo en el que se diseñó primero.

Variables de color

Nombrar colores por su rol (--accent, --text-dim) en vez de su valor (#5865f2) facilita cambiarlos sin tocar cada componente.

Contraste suficiente vs. insuficiente

Texto legible

Ratio ≈ 7:1 — cómodo de leer incluso con baja visión o en pantallas con brillo bajo.

Texto poco legible

Ratio ≈ 1.8:1 — falla el estándar AA; ilegible para buena parte de los usuarios.
