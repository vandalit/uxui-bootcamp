CSS — lo básico

El lenguaje que define la apariencia visual del HTML — color, tamaño, espaciado, posición — sin tocar el contenido ni el significado de la estructura.

Selectores

Apuntan a qué elementos se les aplica un estilo: por etiqueta (p), por clase (.tarjeta) o por id (#hero). La especificidad decide cuál gana si hay conflicto.

Box model

Todo elemento es una caja: content, rodeado de padding, luego border, luego margin. Entender esta caja explica por qué algo "se mueve" al cambiar un tamaño.

Flexbox

Layout en una dimensión (fila o columna). Ideal para alinear y distribuir elementos dentro de un contenedor — barras de navegación, tarjetas en fila, centrar contenido.

Grid

Layout en dos dimensiones (filas y columnas a la vez). Ideal para maquetar la estructura general de una página o secciones con un patrón regular de celdas.

Media queries

Reglas condicionales — @media (max-width: 680px) { ... } — que aplican estilos distintos según el tamaño de pantalla (u otras características del dispositivo). Son la herramienta técnica detrás del diseño responsive.

Responsive vs. adaptativo vs. líquido (fluido)

Los tres buscan que un sitio funcione en distintas pantallas, pero resuelven el problema de forma distinta:

Líquido / fluido

Todo se mide en unidades relativas (%, fr). El layout se estira o contrae de forma continua con el ancho de pantalla, sin puntos de quiebre — pero a tamaños extremos puede verse demasiado angosto o demasiado ancho.

Adaptativo

Un set fijo de layouts predefinidos (ej. para móvil, tablet, desktop). Al cruzar un punto de quiebre, salta de un diseño fijo a otro — sin estados intermedios entre ellos.

Responsive

Combina ambos: usa unidades fluidas dentro de cada rango, y media queries para reorganizar el layout en puntos de quiebre clave. Es el enfoque más usado hoy porque junta lo mejor de los dos anteriores.
