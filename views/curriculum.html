Lean UX

Ciclos cortos de pensar - construir - validar, enfocados en hipótesis y MVPs en lugar de entregables exhaustivos.

Design Sprint

Proceso acelerado de 5 días para validar una idea antes de construirla.

Research

Métodos para entender a usuarios y validar decisiones, agrupados por enfoque.

Métodos cualitativos

Entrevistas

Conversaciones semiestructuradas para entender motivaciones y contexto.

Card sorting

Organización de contenidos por parte de usuarios para definir arquitectura de información.

Usability testing

Observación de usuarios interactuando con un prototipo o producto real.

Métodos cuantitativos

Encuestas

Recolección de datos a escala para detectar patrones y priorizar hipótesis.

A/B Testing

Comparación de variantes en producción para medir impacto real en métricas.
