JavaScript — lo básico

El lenguaje que hace interactiva una interfaz — reacciona a lo que hace el usuario y actualiza lo que ve, sin tocar la estructura (HTML) ni la apariencia (CSS) por sí mismo.

Eventos

El navegador "escucha" interacciones del usuario — click, scroll, input, submit — y dispara código en respuesta. Todo empieza con un evento.

Estado

Los datos que cambian con el tiempo — un filtro activo, un carrito de compras, una pestaña seleccionada. La interfaz se redibuja cuando el estado cambia.

Condicionales

if / else: mostrar, ocultar o cambiar algo según una condición — por ejemplo, validar un campo antes de enviar un formulario.

Funciones

Bloques de código reutilizable que se ejecutan en respuesta a un evento o un cambio de estado, en vez de repetir la misma lógica una y otra vez.

DOM

El Document Object Model: la representación en memoria del HTML que JS puede leer y modificar — agregar o quitar elementos, cambiar texto, alternar clases.

Asíncronía

Pedir datos a un servidor (fetch) sin congelar ni recargar la página — justo lo que hace este mismo dashboard al cambiar de pestaña o cargar una vista.

Anatomía de un event listener

boton.addEventListener("click", callback)
Elemento y función a ejecutar Evento que se escucha Sintaxis del método

Cuando ocurre el evento "click" sobre boton, el navegador ejecuta callback — ahí dentro se suele leer/actualizar el estado y modificar el DOM.
