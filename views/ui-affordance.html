Affordance y feedback visual

Las señales que le dicen al usuario qué puede hacer con un elemento, y las que confirman qué ocurrió después de que lo hizo.

Affordance

Una propiedad visual que sugiere cómo se usa algo — un botón con sombra y borde redondeado "parece" presionable, sin necesidad de explicarlo.

Estados interactivos

hover, active, focus y disabled — cada uno comunica algo distinto sobre la disponibilidad de un elemento.

Microinteracciones

Animaciones breves (un check que aparece, un botón que se hunde) que confirman que una acción fue recibida, sin interrumpir el flujo.

Estados de carga

Skeletons, spinners o barras de progreso comunican que algo está en proceso — evitan que el usuario piense que la interfaz se congeló.

Confirmación de acción

Un mensaje, color o ícono que confirma que una acción se completó (guardar, enviar, eliminar) — sin confirmación, el usuario repite la acción por duda.

Cursor

El cambio de cursor (de flecha a mano) es una de las señales de affordance más antiguas y universales de la web — indica "esto se puede clickear".
