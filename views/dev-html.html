HTML — lo básico

El lenguaje de marcado que da estructura y significado al contenido de una página — no su apariencia (eso es CSS) ni su comportamiento (eso es JavaScript).

Etiquetas (tags)

Elementos delimitados por <tag>...</tag> que envuelven una parte del contenido y le dan un rol: párrafo, título, imagen, enlace.

Atributos

Pares clave="valor" dentro de la etiqueta de apertura que agregan información — por ejemplo href en un enlace o alt en una imagen.

Texto

<p> para párrafos. <span> para texto en línea sin significado propio — útil para aplicar estilo a una palabra suelta dentro de una frase.

Títulos

Jerarquía <h1> a <h6>: define la estructura del documento, no solo el tamaño visual — debería existir un único <h1> por página.

Clases (class)

Agrupan elementos para aplicarles el mismo estilo o comportamiento. Un elemento puede tener varias clases, y una clase puede repetirse en muchos elementos.

ID

Identificador único dentro de la página — no se repite. Sirve para anclas (#seccion), referencias puntuales desde JS o relacionar un <label> con su campo.

Semántica

Usar la etiqueta que mejor describe el propósito del contenido (header, nav, main, article, section, footer) en vez de div genéricos para todo. Mejora accesibilidad (lectores de pantalla entienden la página), SEO y mantenibilidad del código.
