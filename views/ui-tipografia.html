Tipografía

Las decisiones de letra que sostienen legibilidad y jerarquía en toda la interfaz — no solo "elegir una fuente bonita".

Familia tipográfica

El set de letras elegido — idealmente máximo 1-2 familias por producto, para mantener consistencia y tiempos de carga razonables.

Escala tipográfica

Una progresión de tamaños predefinida (ej. 12/14/16/20/24/32px) en vez de elegir tamaños arbitrarios para cada texto nuevo.

Peso (weight)

Regular, medium, bold — variaciones de grosor de una misma familia, usadas para crear jerarquía sin cambiar de tamaño.

Interlineado

El espacio vertical entre líneas (line-height). Muy ajustado dificulta la lectura; muy abierto desconecta visualmente el párrafo.

Tracking / letter-spacing

El espacio horizontal entre letras. Útil en mayúsculas pequeñas (ej. etiquetas) para que no se vean apretadas.

Legibilidad vs. decoración

El cuerpo de texto prioriza legibilidad (tamaño, contraste, ancho de línea); los títulos pueden tomar más riesgo expresivo.

Anatomía de una escala tipográfica

Display 32px / 700
Heading 24px / 600
Subheading 18px / 600
Body text 16px / 400
Caption 13px / 400

Cada nivel de la escala tiene un rol fijo: usar "Heading" para un título y nunca para un texto de apoyo mantiene la jerarquía predecible en toda la interfaz, sin decidir tamaños caso por caso.
